# Capítulo 43 — Las luminarias y los nombres (paráfrasis preliminar)

Enoc aprende sobre las luminarias y las fuerzas que acompañan sus movimientos. Se describen nombres, señales y relaciones dentro del orden celestial. El conocimiento que recibe se presenta como una revelación sobre la creación y sus ciclos.
