# Estructura y fuentes del proyecto

## Índice de 1 Enoc
- 1–36: Libro de los Vigilantes
- 37–71: Parábolas (o Similitudes)
- 72–82: Libro Astronómico
- 83–90: Visiones de los Sueños
- 91–108: Epístola de Enoc y materiales finales (incluye las secciones sobre el nacimiento de Noé y el capítulo 108)

Esta división es una guía de trabajo; en las notas se indicarán subdivisiones y diferencias editoriales cuando proceda.

## Política de transcripción y traducción
1. Registrar la edición base y sus datos bibliográficos.
2. Priorizar traducciones o textos con permiso/licencia compatible; alternativamente producir una traducción propia a partir de una fuente de dominio público debidamente identificada.
3. Documentar variantes cuando haya evidencia manuscrita.
4. Marcar fragmentos, lagunas y reconstrucciones.
5. Separar claramente 1 Enoc de Libro de los Gigantes, 2 Enoc, 3 Enoc y las interpretaciones cabalísticas posteriores.
