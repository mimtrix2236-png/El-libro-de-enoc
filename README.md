# El Libro de Enoc

Aplicación Android de lectura con estética de manuscrito antiguo. Proyecto inicial.

## Objetivos
- Lectura por capítulos y páginas, índice y navegación.
- Estilo pergamino / cuero antiguo, con portada ilustrada.
- Marcadores, tamaño de letra y modo oscuro.
- Biblioteca complementaria con fuentes y notas que distingan texto conservado, fragmentos y reconstrucciones.
- Preparación futura de edición imprimible.

**Nota editorial:** se documentarán las fuentes de cada texto y se evitará presentar reconstrucciones o interpretaciones como texto antiguo auténtico.
